# AGENTS.md

## Git

- Do not add the Co-Authored-By: line on commit messages
- Git commit messages must always be in English and respect maximum
  of 72 columns
- Never push to `main`, `master` or `stable`. Always work on a feature branch.
  Checkout feature branch on a worktree at scratchpad and do not change
  current directory branch.
- Never push commits before the user has reviewed the local diff and
  commit message and approved.
- gitlab host is gitlab.netgate.com and glab CLI is available to interact
  with it
- When working on repositories where remote points to gitlab.netgate.com
  make sure user and email are "Renato Botelho do Couto <renato@netgate.com>"
- When working on repositories where remote points to freebsd.org
  make sure user and email are "Renato Botelho <garga@FreeBSD.org>"

## Merge requests

- Do not add Generated by Claude Code message on MRs
- Never create, reply to, or update merge requests before the user has
  approved the MR title, description, and comments.
- When MR is merged, cleanup local worktree and branches.

## Bug tickets

- Tickets are tracked on redmine.netgate.com and information can be read
  using ~/.local/bin/redmine-get script.
